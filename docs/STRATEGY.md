# 打法与胜率说明

## 先回答：能不能“保证胜率”

**不能。** 任何脚本都保证不了，原因很具体：

- 发牌随机：核心卡（阿米娅的助力、坚守的盾、精准的灰喉/空弦）不来，任何打法都会掉战力；
- 账号差异：自选编队/助战干员不同，同一套 build 的上限不同；
- 识别误差：OCR 把干员名读错、商店费用读错，会直接买错/漏买；
- 对战随机性：Boss、敌人词条、装备掉落都会影响结果。

社区里说的“胜率 90%+ / 几乎 100%”都是**熟练玩家手动打**的体感，不是脚本在任意账号上的保证。
这个工具能做的是：把攻略里的成体系打法编码成 build、把胜率变成可统计的指标，然后按你的实机数据迭代。

## 工具里的 5 套 build

| id | 名称 | 目标盟约 | 升级节奏 | 适用 |
| --- | --- | --- | --- | --- |
| `amiya_economy` | 阿米娅·远见奇迹经济 | 远见/奇迹/投资人 | 第 3 回合起 | 叠层、300 层、task-6 |
| `spirit_swift` | 阿米娅·精灵迅 | 精准/灵巧/迅捷/远见/奇迹 | 第 3 回合起，奇数回合升 | 默认刷角标，B 站主流 |
| `amiya_victoria` | 阿米娅·助力维 | 助力/维多利亚/灵巧/远见/奇迹 | 第 3 回合起 | 稳下限，备选 |
| `guard_swift` | 坚守迅捷 | 坚守/助力/迅捷 | 第 3 回合起 | 低配/低难度，最稳 |
| `precision_arcane` | 精准奥术 | 精准/奥术/聚合 | 第 2 回合起 | 远程多、前排压力小 |
| `fast_level` | 速本 | — | 第 4 回合起 | 通用，上限高但吃发牌 |

- `--build auto`（默认）：按策略名和目标自动选。阿米娅 → 精灵迅；坚守/迅捷 → 坚守迅捷；
  精准/奥术 → 精准奥术；`--goal task-6/layer-300` → 经济叠层；其余 → 速本。
- `--build guard_swift` 可以强制指定。
- 攻略里提到但本赛季池子里没有的干员（如远山、暴行）会被自动忽略，实际买谁由
  “目标盟约 + 等阶/费用/是否叠层 + 合成进度”评分决定。

## 工具已经落实的规则

1. 目标盟约优先：命中 build 的盟约 +150/个，叠层干员再 +300，压过普通 6 星；
2. 合成进度：同名卡已有 1/2 张时加分，优先凑三连；
3. 医疗上限：默认最多 1 个，避免前期把经济花在医疗上；
4. 升级节奏：build 的 `upgrade_from_round` 之前只买卡不升级；精灵迅只在奇数回合升级；
5. 安全位：远程/辅助优先放木框高台；
6. 胜率统计：每局记录 win/loss，`status` 显示总胜率和近 20 局胜率。

## 怎么验证与调参

```powershell
# 先跑 10 局，看胜率
python -m spa_farm run --maa "C:/Program Files/MAA" --mode badges --max-runs 10
python -m spa_farm status

# 换 build 对比
python -m spa_farm run --maa ... --build guard_swift --max-runs 10

# 关键目标用经济流
python -m spa_farm run --maa ... --goal task-6 --build amiya_economy
```

如果 10 局胜率低于 60%，把 `progress.json` + 控制台日志 + `screenshots/` 发我，
按输的回合、买卡记录和 OCR 结果调 `policy.priorities` / `upgrade_from_round` / `tiles`。

## 想要更高胜率的现实建议

这个 Python 版的对局执行是简化实现（买卡/升级/固定格位部署），识别和布阵细节不如
Dr-hydra fork 里逐函数移植的那套。**如果目标是稳定刷满 60 胜，最稳的组合是：**

- 用 Dr-hydra 的 MAA 构建（`v6.22.0-spa.1`）跑对局，设置 `medal / 3 次 / 60 局`；
- 用本工具的 `plan` 算局数和阶段、用 `status` 记进度；
- 关键目标（task-1..7）和 300 层按 `docs/REVIEW-fork.md` 里的说明补。

本工具的 Python 执行仍在迭代，build 只是把攻略思路落地，不能承诺胜率。
