# Dr-hydra 版卫戍协议：最优使用方案

目标：用 `Dr-hydra/MaaAssistantArknights` 的 `v6.22.0-spa.1` 构建刷满蚀刻章，
不碰 Python 那套。

## 一、先装对版本

1. 打开 [Release v6.22.0-spa.1](https://github.com/Dr-hydra/MaaAssistantArknights/releases/tag/v6.22.0-spa.1)，
   下载 `MAA-v6.22.0-spa.1-win-x64.zip`（约 295MB）。
2. 解压到**另一个目录**（例如 `D:\MAA-spa`），不要覆盖你现在的官方 MAA。
3. 运行 `MAA.exe`，连接 MuMu，确认能正常截图/点击。
4. 这个版本号刻意低于官方稳定版，GUI 里如果提示更新，**不要更新**，否则会把卫戍功能覆盖掉。

## 二、游戏侧准备（缺一不可）

- MuMu 分辨率 1920×1080 横屏，游戏默认主题；
- 卫戍协议里「更换主题」保持默认；
- 关闭游戏内按键提示（会挡住「确认升级」的文字，OCR 读不到升级按钮）；
- 游戏停在卫戍协议主界面，有未完成对局先手动放弃；
- 如果有「自选编队」，按你的账号把常用的 V/VI 阶干员配好（标准模式胜率更高）。

## 三、刷角标设置（关键，直接决定局数）

小工具 → 牛杂 → 卫戍协议：

| 选项 | 值 | 原因 |
| --- | --- | --- |
| 模式 | 刷角标 | 不是刷等级 |
| 目标 | 策略徽章（medal） | 对应「20 个策略普通标识」 |
| 模拟 | 极速模拟 | 最快，且计入通关 |
| 低配模式 | 有自选编队就**不勾** | 标准编队胜率更高 |
| 彩色角标 | **不勾** | 6 次是角标镀层，不是蚀刻章条件 |
| 最大通关局数 | **60** | 20 策略 × 3 次 = 60 胜，正好覆盖两个条件 |

> 默认值是 20，会在第 20 胜时停下，只完成约 7 个策略；这是最容易踩的坑。
> 也不要让它刷满 31 个可用策略（93 胜），那是 55% 的额外局数。

## 四、跑的顺序

1. **阶段 1：策略徽章**（上面的 60 局）
   - 每局约 10~15 分钟；按 80% 胜率算，约 70~75 次尝试、12~16 小时。
   - 失败不消耗「累计通关」，会自动重试同一策略。
2. **阶段 2：关键目标 task-1..7**
   - 模式仍是刷角标，目标依次选 `task-1` … `task-7`；
   - 每次「最大通关局数」先填 3，跑完看结算/奖励里该目标是否完成；没完成再加 2 局。
   - 这 7 条对应前置蚀刻章里的关键目标。
3. **阶段 3：300 层**
   - 目前 fork 没有「300 层」这个 goal（`GoalTaskSpec.layers` 字段没被使用，见审查文档）；
   - 用 `task-6`（奇迹/远见/投资人）的经济流反复跑，局内看核心盟约层数；
   - 这是唯一需要你手动确认的蚀刻章。

## 五、进度与胜率怎么看

- GUI 的日志会打印：
  ```
  【对局结算】第 12 场：模拟完成(胜利) | 策略：阿米娅 (通关 2/3) | 累计通关：12/60 | 策略刻章完成：4/31
  【刻章达成】策略「阿米娅」已达成 3 次通关刻章！
  ```
- 用「60 局」配置时，看到 `累计通关 60/60` 就停，不用管 `策略刻章完成 x/31`（它按 31 个可用策略算，不是蚀刻章要求）。
- 胜率 = 胜利场次 / 总尝试场次，日志里 `第 N 场` 是尝试数。

## 六、常见问题

- 卡在策略选择：确认从卫戍协议主界面开始、没有未完成对局、默认主题。
- 升级点不动：关闭按键提示；这是原文明确要求的硬性前置。
- 一直输：先确认「低配模式」是否该开/关；标准编队缺核心干员时胜率会明显下降。
- 想省时间：只在**极速模拟**刷；不要为了「彩色角标」勾 6 次。
- 更新提示：不要更新，否则卫戍插件消失。

## 七、为什么这是「不改代码」的最优解

- 60 胜 = 20 策略 × 3 次，刚好满足「20 个策略普通标识」+「60 胜」两枚蚀刻章；
- 刷 31 个策略要 93 胜，多 33 局（约 6~8 小时）；
- 勾彩色（6 次）要 120+ 胜，对蚀刻章没有额外帮助；
- 默认 20 局会提前停，导致你以为刷完了其实只完成 7 个策略。

这些都不需要重新编译，改设置就行。
